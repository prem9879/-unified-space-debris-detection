# User Guide

## Typical Analyst Workflow

1. Log in with analyst credentials.
2. Open dashboard and monitor live track feed.
3. Upload image or video frame for multimodal detection.
4. Inspect confidence heat and tracked trajectories.
5. Run collision assessment for high-risk object pairs.
6. Trigger alerts to email/SMS/webhook channels.
7. Generate PDF/XLSX reports for mission review.

## Mobile and Touch

- Orbit scene is touch friendly.
- Panels stack automatically on narrow screens.

## Theme

- UI foundation supports dark/light modes; current default is dark mission profile.
