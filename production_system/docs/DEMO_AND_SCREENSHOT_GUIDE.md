# Demo and Screenshot Guide

## Suggested Captures

1. Login + dashboard load (desktop)
2. Orbit visualization with live stream cards
3. Drag-and-drop upload and detection response
4. Collision assessment result panel
5. Alert trigger and history
6. Report generation output (PDF/XLSX)
7. Mobile responsive view

## Demo Video Script (90 seconds)

- 0-10s: Overview of command dashboard.
- 10-25s: Upload debris frame and show detections.
- 25-40s: Open orbit scene and trajectory timeline.
- 40-55s: Collision assessment and time-to-impact result.
- 55-70s: Trigger alert to webhook channel.
- 70-90s: Generate and open PDF report.

## Export Targets

- GIF: 1280x720, 12-20 fps
- MP4: 1920x1080, H.264
- Include subtitles for mission-readiness presentations.
