# Validation Report Template

## Dataset

- dataset name/version
- manifest digest
- split seed
- class balance

## Model

- model family/version
- checkpoint hash
- preprocessing settings

## Metrics

- accuracy/precision/recall/F1
- calibration (ECE/Brier)
- false alarm rate
- confidence intervals

## Acceptance

- calibration gate pass/fail
- false alarm threshold pass/fail
- min recall threshold pass/fail
