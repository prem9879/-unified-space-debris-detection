# Decision Support Doctrine

## What the model can decide

- prioritize observations for analyst review
- classify likely debris/non-debris candidates
- suggest urgency tiers for follow-up

## What only humans can decide

- mission-impacting conjunction actions
- policy/legal escalation decisions
- cross-agency operational directives

## Mandatory escalation tiers

1. Tier 1 (Low): analyst review within routine queue.
2. Tier 2 (High): immediate analyst confirmation + secondary sensor check.
3. Tier 3 (Urgent): command-level notification, independent verification, and documented decision log.

## Accountability

- every urgent recommendation requires human sign-off
- all decisions must reference model version + manifest digest
